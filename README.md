# Color Helper

## Description

**version 1.0**

Helps determine between colors for those with color-blindness

## Developer

Cai Mcdonnell

## Example

To run the program, give the following commands:

```
Input Colors in RGB; Red, Green, and Blue, all in one line.
```

Here is an example of the program running:

```
Please input your 1st color code in RGB!
0 -20 2354
RED: 0 GREEN: 0 BLUE: 255
Your Color is Blue!
Please input your 2nd color code in RGB!
4354 4545 545
RED: 255 GREEN: 255 BLUE: 255
Your Color is White!
```
